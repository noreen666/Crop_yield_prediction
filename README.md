# Crop_yield_prediction
**Project Overview**

This project focuses on analyzing agricultural data and building Machine Learning models to predict crop yield.

The project combines Data Analysis, Data Visualization, Machine Learning, and a Streamlit Web Application to provide useful insights and predictions from the agricultural dataset.

--------------------------
 **Technologies Used**

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Power BI
- Streamlit

🤖 **Machine Learning Models**

The following Machine Learning models were used:

- Linear Regression
- Random Forest Regression

The models were trained and evaluated to predict crop yield based on the available agricultural features.



📊 **Data Analysis & Visualization**

Power BI was used to create interactive visualizations and dashboards to explore the dataset and identify important insights related to crop yield.



🌐**Streamlit Web Application**

A Streamlit Web Application was developed to provide an easy-to-use interface for interacting with the Machine Learning prediction model.
